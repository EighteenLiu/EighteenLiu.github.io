02这段实习的技术性质

这批评审与统计报表工作有比较固定的链路：

原始台账（.xls / .xlsx）
  → 字段清理与标准化
  → 有效案件筛选与指标统计
  → 写入 Excel 模板 / 生成统计表
  → 用 Word 模板渲染报告
  → 输出日志、校验数量与结果
  → 清理运行期临时文件

从仓库说明可以确认的实现原则包括：模板与旧项目只读、运行期临时目录固定在项目目录而不写入 C 盘、批处理结束后清理中间文件、数据库一致性校验、以及把面向桌面的操作封装为 Tkinter 或 PyQt 类界面。

我 GitHub 近半年仓库的 README、提交记录与项目结构
